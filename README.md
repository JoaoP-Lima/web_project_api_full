## 📖 Descrição

Aplicação web para compartilhamento de imagens, com sistema de autenticação de usuários, gerenciamento de perfil e interação através de curtidas.

## ✨ Funcionalidades

- Criação de conta e login de usuários.

- Personalização do perfil com nome, descrição e foto de perfil.

- Criação de cartões com imagem e descrição.

- Visualização de cartões publicados por todos os usuários registrados no site.

- Curtidas de cartões como forma de interação entre os usuários.

- Exclusão de cartões pelo próprio usuário que os publicou.

- Logout da conta

## 🚀 Implantação

O projeto foi implantado em um servidor remoto utilizando Nginx como servidor web e proxy. O back-end é executado com PM2 e o front-end é servido pelo Nginx.
