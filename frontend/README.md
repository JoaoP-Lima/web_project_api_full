# Tripleten web_project_around_react


Aplicação web sobre locais e paisagens, permitindo que usuários visualizem cartões, curtam publicações, editem seu perfil e atualizem sua foto de perfil.

O projeto foi desenvolvido utilizando JavaScript e arquitetura baseada em React, assim com maior reutilização de componentes e melhor organização do código.

## Funcionalidades

- Criação de novos cartões.

- Exclusão de cartões com confirmação.

- Curtir e descurtir cartões.

- Edição de informações do perfil.

- Atualização da foto de perfil.

- Visualização ampliada de imagens em popup.

- Validação de formulários.

- Integração com API REST.

- Interface responsiva.

- Área de login

-Área de cadastro
